3.  Technology  Stack  
Because  lightning-fast  latency  is  non-negotiable  for  an  inline  autocomplete  experience,  the  
stack
 
leverages
 
Groq's
 
LPU
 
inference
 
hardware
 
and
 
modern
 
extension
 
bundling

Layer  Technology  Purpose  
Extension  Framework  
WXT  +  Vite  +  TypeScript  
Modern  boilerplate  for  Manifest  V3  extension,  handling  hot-reloading  and  isolated  content  script  compilation.  
Frontend  UI  Layer  
Shadow  DOM  +  Tailwind  CSS  
Ensures  Pretext's  interactive  dropdown  styles  are  never  broken  or  overridden  by  the  host  website's  CSS  (e.g.,  ChatGPT's  dark  mode  styles).  
Backend  &  DB  Layer  
Supabase  (PostgreSQL)  
Handles  user  session  management,  database  rules,  analytics,  and  token  usage  tracking.  
Authentication  Google  OAuth2  (via  Supabase  Auth)  
Single-click  user  onboarding  natively  matching  Chrome  account  context.  
AI  Inference  Engine  
Groq  API  (llama-3.1-8b-instant)  
Delivers  800+  tokens/sec  speeds.  Essential  for  parsing  text  and  spitting  out  dropdown  options  instantly.
